## Run Locally

Clone the repository:

\`\`\`bash
git clone https://github.com/alibelhrak/alibelhrak.github.io.git
cd alibelhrak.github.io
\`\`\`

Start a local server:

\`\`\`bash
python -m http.server 8000
\`\`\`

Open http://localhost:8000 in your browser.

Alternatively, open `index.html` directly.

## Deployment

The website is hosted using GitHub Pages.

Changes pushed to the configured publishing branch are deployed through GitHub Pages.
